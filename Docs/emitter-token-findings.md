2. **MIX mute tap — FULL TOGGLE, UNDOABLE (Paul).** The live output mute is **not a boolean**. It is a per-output 16-cell rhythmic gate. So a MIX-emitter tap flips the whole output between all-cells-sounding (`0xFFFF`) and all-cells-muted (`0x0000`); the emitter reads **muted whenever any cell is gated** (`hasMute`, `cells16 != 0xFFFF`); a tap on a partially-patterned output clears it to fully on/off; and it **records one undo step** through the existing `onEditOutputMute` path, matching the MUTE tab (the ferry's §5.1 "none" was premised on matching a header ring that does not exist). The ferry's named field `euclideousMainOutMask` is a dead, unread field — not this.
