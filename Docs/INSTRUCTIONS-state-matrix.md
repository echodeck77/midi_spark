## The problem, named
Pick-then-paint has a DEAD FIRST TOUCH: a slice tap does nothing
legible until a brush is picked — reads as non-responsive.

## The replacement: ROWS = OPTIONS · COLUMNS = THE 8 STEPS
Every state-painted control becomes a MATRIX: tap cell (state,
step) = that step takes that state. No brush, no mode, every
touch responds instantly. Row headers (left edge) carry the old
palette's glyph + name — permanent and positional.
- **Exclusive state sets** (TUTTI PATTERN's shapes · RATCHET
  PATTERN's counts · LENGTH's states · BURST PATTERN's
  burst/carry/rest · VELOCITY PATTERN when it lands) = a
  RADIO-PER-COLUMN: exactly one lit cell per step.
- **Flag sets** (GROOVE-class stackables) = TOGGLES: several lit
  per step is legal.
- **Sizes**: mostly 3–4 rows × 8; TUTTI PATTERN = 8×8 (the house
  can live with that). ROTATE + RATE chips stay beneath,
  unchanged; SPAN chips unchanged.
- **Exempt**: MOD STEPS and any continuous bar-draw (values, not
  states — the drag-draw stays).
- The brush/palette row RETIRES on converted panels; the matrix
  IS the palette and the pattern at once.
The read-back bonus: the whole pattern is visible as geometry —
a comping figure or a roll map legible from across the room.

- **SPAN becomes a dial: 1 · 2 · 3 · 4 · 6 · 8 · ×2 · ×4** —

  absorbed into one ladder). CELL = 1, ROW = 8: the old binary
  = the endpoints; migration is a relabel.
- **The odd spans are the prize**: a pattern cycling every 3 or
  5 columns against the 8-column row = POLYMETER at processor
  grain (the loop-set law's sibling; the engine cost is the
  same one character: index = rowStep % N, ×-spans =
  floor across passes — pure, replay-safe).
- **The anchor pin**: spans anchor at the ROW'S ORIGIN (column
  0) — all cells of the colour share the pattern's phase;
  ROTATE still shifts it. Deterministic, and N=8 exactly
  matches today's ROW behaviour.
- **Who gets it**: every current CELL|ROW holder (EUCLID ·
  BURST family · TUTTI PATTERN · the matrices' chrome) + MOD
