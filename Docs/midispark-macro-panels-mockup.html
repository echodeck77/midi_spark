BEFORE/AFTER = the base value and the target; the macro stores the delta and OFFSETS the base (never rewrites it). A slider macro morphs continuously; a toggle snaps. Bindings survive mutate / randomize.

Hand-ride the macros live. Faders ride the 8 sliders (0…1); pads toggle the 8 toggles (OFF = base · ON = the bound offset). The grid keeps playing.
