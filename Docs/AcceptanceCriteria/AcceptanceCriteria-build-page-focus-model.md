## 1. THE FOCUS ECONOMY (attention follows sound made visible)
- The page has ONE workshop voice at a time (Paul's mutual-
  exclusion ruling). **Whichever zone owns it is LIT**: full
  saturation · accent border · a **● PLAYING badge** in its header
  · and in the machine phase, **the snake's dotted thread PULSES**
  (signal animating door→wire — the machinery performs its
  aliveness; this is the "screams I'm playing" requirement).
- The other workshop zone **dims to ~60%** — touchable, never
  disabled, visibly not-where-the-music-is.
- **The PLAY grid sits OUTSIDE the focus economy**: always
  sounding, so it never competes for the lamp — calmest zone on
  the page; it wakes only when an apply arms it (bands pulse to
  receive).
- **The transition teaches**: ~150ms crossfade of light when the
  voice moves. No tutorial needed; the lamp changing hands IS the
  lesson.

## 2. STAGING'S DUAL BEHAVIOUR (focus selects the job — no mode
## button anywhere)
- **VOICE ON STAGING = an instrument**: rung taps PICK (boundary-
  deferred per SINGLE's law) · column keys LOOP · every touch
  audible.
- **VOICE ON PALETTE = a workbench**: same surface, taps SELECT
  (machinery follows, nothing switches audibly) · drags place/
  move/litter · edits arrange WITHOUT performing (stocking is
  silent).
- **THE GRAB (pin, device-tunable)**: in workbench state, cell
  taps stay edit-selects; **the COLUMN KEYS and the staging ●
  badge are the deliberate grab** ("staging, sing"). Focus
  otherwise follows the last musical gesture (PLAY THIS CELL /
  RANDOMIZE audition pulls it left; rung taps keep it on a lit
  staging).
- **The silence tell**: dimmed staging shows active rungs as
  HOLLOW rings (picks at rest); the voice arriving fills them.

## 3. PLACEMENT — the row buttons return (the workbench's primary
## verb)
- **A row-selector rail on staging's LEFT edge** (missing from the
  skeleton — add it): with a cast colour selected, **tap a row =
  fill the row with that colour** (the 3-press cycle grammar:
  fill → [second state] → clear; exact cycle = Paul's device
  call).
- Drag swatch→cell for precision; drag within grid = move; drag→
  litter = clear. All six landings live, all SILENT in workbench
  state.
- **APPLY TO STAGING stays the generated path beside the manual
  one**: the roll fills eight variation rows; the row buttons fill
  one chosen row — the machine's ladder and the hand's ladder,
  same surface, same rail.

## 4. ONE REMOVAL
**The header's global SINGLE|MULTI toggle has NO jurisdiction on
BUILD** — hide it on this page (staging is always SINGLE-natured;
the play grid's bands own their own behaviour). It remains scoped
to the legacy GRID view until that view inherits bands. A global
mode contradicting the band rails would re-teach the exact
confusion this page ends.

## The flow, as one sentence (the acceptance test)
Build the machine (left lit, snake pulsing) → stock the grid (row
buttons + drags, silent) → grab the voice (column key) → play the
grid (picks, loops) → deploy (FLATTEN | COPY ROWS, tap the band —
which pulses to receive). At every instant exactly one thing on
screen says "I'm playing," and the light never lies.
