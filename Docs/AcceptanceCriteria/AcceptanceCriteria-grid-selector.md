## THE PAGE
A button beside LIBRARY opens a FULL-PAGE 8×8: **each cell = one
complete MIDI chain, mutually exclusive** (tap = it plays, the
previous stops — the SINGLE grammar at library scale). The RIGHT
column shows the selected cell's chain (read-only + its eye; this
page browses, the normal panel edits). The page's buttons:
**COMMIT · CANCEL** only.
