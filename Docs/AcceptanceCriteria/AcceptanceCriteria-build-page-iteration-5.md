# Three rulings on the as-built screenshot.

## 1. START/STOP = VIEW STATE (the lamp handles formalised)
- **STOPPED = the EDIT VIEW** · **PLAYING = the PERFORMANCE VIEW**
  — per grid, driven by its top handle. The tell: **the row
  buttons CHANGE APPEARANCE between states** (edit dress vs
  perform dress), and the grid's touch semantics follow (edit
  verbs when stopped; performance controls when playing).
- Applies to BOTH the play grid AND staging (staging's handle
  toggles workbench ↔ instrument — the dual-behaviour model now
  has a visible state instead of an inferred focus).
- **THE FIRST-RUN MOMENT**: the play grid ships STOPPED; the
  user's FIRST deployed part **springs it into life** (auto-start
  on first apply) — the instrument introducing itself. 
- The always-plays law amends accordingly: the stage plays unless
  the USER stops it (their transport choice; nothing else stops
  it). Workshop voice mutual-exclusion (machine vs staging)
  stands; the play grid remains outside that contest.

## 2. ONE MUTATE
The bottom-bar MUTATE (beside RANDOMIZE) is REMOVED. The staging
strip's MUTATE is THE mutate (targets the selection per the dice
spec). One word, one home.

## 3. DELETE IS SHARED — the litter's successor
One DELETE verb serves ALL THREE grids: arm it, then
- tap a STAGING or PLAY cell = clear it;
- tap a CAST swatch = **delete the colour AND its placed cells**
  (the litter's old semantics: NO dialog, ONE undoable step, a
  brief flash of what it took — "−1 colour · 5 cells").
The litter box stays retired; the verb replaced the furniture.
