## A. §13.1 — AVOID as built (coincidence test + which side of the RHYTHM strip)
- AVOID currently lives in **PITCH** (`EuclideousAnswerPitchMode.avoid`, `Models.swift:1318` → resolved `EuclideousListenPitchMode.avoid`, `Models.swift:980`), gated by `answerPitchOn`; `segPitchMode` at `Router.swift:5473`. The Router hole-punch is `Router.swift:4166–4184`.
- The coincidence test is **`euclideousLaneClockStepIsHit(clock, atBeat:)`** (`Derivations.swift:9597`): take THIS lane's own strike beat `b` (its TILT/offset delay included), `tick = floor(b/sub)`, read that source tick's **rhythm-hit flag** via the shared per-tick core `euclideousLaneChainTick`. Robust across step counts / rates / swing / TILT / ratchets. The older strict-instant `euclideousLaneClockStrikesAt` (`Derivations.swift:9610`) is kept, unused.
- **Which side (§5.4): the RAW source clock, BEFORE the AVOIDing lane's DELAY/FEEL/SPEED/DIRECTION.** The source clock is captured in the clock pre-pass from the SOURCE lane's own `euclidBuf` (its own OFFSET/TILT/MISS/DIRECTION baked in) at `Router.swift:3268–3274`. The DELAY/FEEL/SPEED/DIRECTION transforms are the COPY/FILL *borrow* transforms (`Router.swift:3086–3158`) and only fire for a lane that is itself COPY/FILL — they never touch the AVOID read. **MEET and AVOID both filter against this raw source clock** (the side AVOID uses today); MEET is the clean inverse of the same predicate.
- Source audibility: a LANES-muted / solo-silenced source step punches no hole (`euclideousLaneMayStrike`, `Router.swift:4174`). MEET uses the same predicate inverted, so §10.3's partition (MEET ⊎ AVOID = own hits) holds by construction.
- Commits: **`4cb3c12`** (step-based rebuild, added `euclideousLaneClockStepIsHit`), **`12945ef`** (the earlier time-based hole-punch), **`64f951f`** (fuzz re-pin). Status log: `euclideous-status-log.md` "AVOID IS STEP-BASED".

## B. §13.2 — SHADOW's note-now (used by MIRROR §6.2 and DODGE §6.3)
- SHADOW takes the source's **most-recent captured strike** (sticky), from the per-lane echo-cycle ring `euclideousEchoCurrent[source]` / `euclideousEchoLast[source]` (`Router.swift:3889`): the last strike of the source's current cycle, else the last of the previous completed cycle. A **silent** source (never struck this run) ⇒ the follower's hit is **silent, no substitute**.
- Each captured strike carries its **source-pool rank** `srcRank` (`EuclideousEchoCycle.ranks`, `Router.swift:950`).
- SHADOW is applied **before INTERVAL and OCTAVE**: `strikeFrom` (`Router.swift:3882–3887`) fixes `note` (the source note), then `euclideousListenMoveByInterval` (INTERVAL+OCTAVE) then `outShift` (out-transpose) then `addPitch`. **MIRROR/DODGE transform `note` BEFORE `euclideousListenMoveByInterval`**, letting the existing tail run.
- Pool is ranked **ascending** (rank 1 = lowest, `riffResolve` `Derivations.swift:1646`); `euclideousPoolRankOf` (`Derivations.swift:10702`) is pitch→rank nearest, **lower-on-tie** — exactly §6.2's tie rule (but it scans ranks 1…8; see §D).

3. **TRADE does NOT exclude RHYTHM/PITCH today** — `euclideousAnswerHasCycle` ORs trade with the rows (`AnswerTab.swift:18`), the Router runs a cycling row AND a trade on one lane (`Router.swift:5470` + `:3737`), and tests deliberately combine them. §4 adds the exclusion (effectiveRows forces rhythm/pitch off while trade is on; UI dims to 32%; a tap on a dimmed control turns trade off then acts). **Breaks** `AnswerRouterTests` "test 11" (`:268`) and `AnswerTradeReviewTests` combos — the ferry replaces test 11 (new §10.7).

6. **The board draws lane 1's chip for a trading lane 3 as "FOLLOWS YOU"; this text wins (§4.3):** a trading lane isn't following, so that chip is ordinary. Also the chip string stays **"FOLLOWS YOU"** (ANSWER v2 doesn't rename it — that's the *amendment*, not landed).
