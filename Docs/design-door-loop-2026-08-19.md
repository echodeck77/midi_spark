## THE HEADLINE — THE DOOR LOOP: a latch that remembers rhythm
Record a door's RAW INPUT stream for N bars; it cycles back as the
living input — exactly as if the hands were still playing.
Determinism free (looped input events ARE input events). Per-door:
R1 loops the changes while R2 stays live for the line — or both
loop, the hands move to the grid. The one-person duet completes.

## THE RIDERS (house-grade)
- **RETRO-CAPTURE by default**: the CATCH ring at the door —
  double-tap keeps the last N bars ALREADY played (never arm,
  never lose the take with the feel). BARS chip grammar reuses
  the catch stage's (1·2·4·8, non-destructive slice).
- **OVERDUB = the latch's own modes, extended in time**: ADD =
  layers accumulate across passes · CHORD = replace. Existing
  vocabulary, new axis.
- **PLAYBACK IS RE-ASKING, not replaying** (it's INPUT): playback
  transforms — RATE (half/double-time the progression) ·
  TRANSPOSE · QUANTIZE-ON-PLAYBACK (record loose, play tight;
  or keep FEEL). The loop is a legal MOVING FRAME for RIFF's
  FOLLOWING mode: record the changes once, capture melodies
  against them forever.

## THE STRUCTURAL IDEA — THE PROGRESSION REEL
Record the whole song's harmony in ONE take; **scenes address
SECTIONS of it** (scene 1 → bars 1–4, scene 2 → bars 5–8): the
arrangement moves the band AND the harmony, no re-latching, no
four-door ceremony. The doors-as-sections idea and the input loop,
fused.
