## The model
**The macro is the one automation currency**: params bind to
macros; macros apply by hand, by cell, or by span. Everything =
base ⊕ offset (the existing engine); boundary-deferred; drawn =
config (deterministic); defaults-recede renders bases dim,
overrides bright.
**SIXTEEN MACROS, TWO SPECIES**:
- **8 TOGGLE macros** — two-state: OFF = base · ON = the bound
  offset applied (the punch/switch species; a toggle can gang
  several params into one named MOVE).
- **8 SLIDER macros** — continuous (the ride species).

## The four tabs (the part page's bottom band, collapsible)
1. **BIND** — the chain list, stages self-named; tap a control →
   assign to a macro (pick species + slot; toggles also set
   their ON value here). A macro gangs many params. ADD BINDING;
   bindings listed per macro.
2. **PLAY** — the live surface: **8 pads (toggles) + 8 faders
   (sliders)**, ridden by hand; grid untouched.
3. **PUNCH** — arm a macro chip (the glow = the mode) → tap
   CELLS: per-cell application (toggle = state-per-cell ·
   slider = value drawn as the bar). Tap the chip again = out.
   CLEAR (one undo) while armed.
4. **SPAN** — arm a macro → the ladder chip (1…16 · ×2 · ×4) →
   apply across the extent (slider spans = drawn sweeps; the
   ×-spans = multi-pass breathing). Same glow/exit/CLEAR.
e-brush legal on any armed canvas; overrides SURVIVE
mutate/randomize (yours; the roll changes the base).

## Buttons, total
The band handle · 4 tabs · 16 macro chips (8+8) · ADD BINDING ·
the span ladder chip · CLEAR. Nothing else.
